## Project Overview
This educational project demonstrates Data Analytics and Machine Learning techniques for studying student academic performance and illustrative academic-risk patterns using synthetic data.

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn and Jupyter Notebook.

## How to Run
1. Install Python 3.9 or later.
2. Run `pip install -r requirements.txt`.
3. Open `Karan_Kumar_Project.ipynb` in Jupyter Notebook/JupyterLab.
4. Run all notebook cells.

## Dataset
The notebook generates synthetic data. No real student personal or academic records are used.

## Repository Files
- Karan_Kumar_Project.ipynb — complete project code

## Responsible Use
The risk categories are illustrative and must not be treated as definitive judgments about real students. Real-world educational AI requires privacy protection, validation, fairness checks and human oversight.
